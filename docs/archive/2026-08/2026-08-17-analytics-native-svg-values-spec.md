# Analytics 原生 SVG 数值展示设计

日期：2026-08-17

状态：已实现

## 背景与根因

Analytics 当前只展示一条已选口径的逐日趋势，数据量固定为 1、7、30 或 90 个点。`TrendView` 已经完成折线坐标计算，但图表只绘制底部基线和少量日期标签，没有 Y 轴刻度或横向网格；数据点及其 SVG `title` 只在不超过 7 天时生成。因此 30 天和 90 天视图只能看到折线高度，无法直接读取具体数值。

本次改动补全现有原生 SVG 的数值表达与交互，不引入 Recharts、uPlot、Chart.js、Ant Design Charts、ECharts 或其他图表运行时依赖。

## 目标

- 用整数 Y 轴刻度和横向网格表达折线的数值范围。
- 在不造成重叠时常驻显示非零数据点的具体数值。
- 让每个日期都能通过鼠标悬浮、键盘操作或手机点击读取精确日期与 PV/UV。
- 保持现有项目、范围、事件和 PV/UV 筛选行为以及 API 契约不变。
- 保持 1、7、30、90 天视图在桌面和手机上的可读性。
- 不新增前端运行时依赖。

## 非目标

- 不增加第二条折线、总量卡片、明细表或新的统计口径。
- 不增加缩放、拖拽、框选、导出、动画或自动刷新。
- 不修改 `/api/track/trend`、数据校验、筛选持久化或 Backend。
- 不建立通用图表组件库；本次只服务 Analytics 的单序列趋势。

## 方案

### 1. 图表刻度与布局

图表继续使用固定逻辑坐标系和响应式 SVG。Y 轴从 0 开始，根据当前所选口径的最大值生成整数刻度：

1. 以约 4 个区间为目标计算原始步长。
2. 将步长归一为不小于 1 的 `1 / 2 / 5 × 10^n` 整数。
3. 将轴上限向上取整到步长的整数倍。
4. 从 0 到轴上限生成完整刻度。

例如最大值为 3 时显示 `0、1、2、3`；最大值为 88 时显示 `0、20、40、60、80、100`。折线使用轴上限而不是原始最大值换算 Y 坐标，使折线、网格与刻度严格对齐。

每个 Y 轴刻度绘制一个格式化数字和一条横向网格线。左侧留白根据最长刻度文字估算，避免较大数字被裁切。X 轴沿用现有规则：7 天以内显示全部日期，更多日期显示首日、中间日和末日。

### 2. 常驻数值标签

所有非零数据点都是常驻标签候选。标签使用与 Tooltip 相同的中文数字分组格式，并绘制在数据点上方；靠近图表顶部时改为绘制在点下方，避免越界。

为防止连续有数据时文字相互遮挡，标签选择使用确定性的碰撞过滤：

- 最新的非零点优先级最高，全局最大值次之，其余候选按日期倒序处理。
- 每个候选先尝试点上方，再尝试点下方；只有某个位置的估算文字边界不与已保留标签相交时才显示。
- 如果高优先级候选的两个位置都发生碰撞，则保留已有的更高优先级标签，不强行叠加文字。
- 被过滤的点仍保留折线和交互命中区域，并可通过 Tooltip 读取精确值。

合成稀疏数据中，`08/16 PV = 3` 和 `08/17 PV = 1` 都应常驻显示。

### 3. 精确值交互

`TrendView` 保存临时悬浮索引和固定索引；固定索引存在时优先显示固定项，否则显示临时悬浮项：

- 每个日期在绘图区拥有一个透明的纵向命中区域，区域边界位于相邻日期的中点。
- 鼠标进入命中区域时更新临时悬浮项；离开图表时清除临时悬浮项，但不清除已经固定的项。
- 点击或触摸命中区域时固定对应日期，点击其他日期切换固定项。
- SVG 本身只占一个键盘 Tab 停靠点。获得焦点时默认激活最新日期，左右方向键逐日移动，`Home`/`End` 跳到首日/末日，`Escape` 清除固定项。

激活后在对应点附近绘制 Tooltip，内容严格为日期、当前口径名称和完整格式化数值，例如：

```text
2026-08-16
PV  3
```

Tooltip 根据数据点位置自动向左或向右展开，并限制在 SVG 边界内。交互只改变当前激活索引，不重新请求数据。

### 4. 可访问性与响应式行为

- SVG 保留 `role="img"`，`aria-label` 增加键盘读取提示。
- 图表提供隐藏说明，列出当前范围内每个日期的所选口径值，使屏幕阅读器不依赖视觉折线或鼠标 Tooltip。
- 键盘改变激活日期时，以礼貌播报方式更新日期与数值。
- Tooltip 和常驻标签不以颜色作为唯一信息来源。
- 小屏幕下图表保持可读的最小宽度，`figure` 允许横向滚动；页面本身不产生整体横向溢出。
- 命中区域覆盖完整绘图高度，手机无需精确点中小圆点；触摸交互不阻止页面纵向滚动。
- `prefers-reduced-motion` 行为保持不变，本次不新增动画。

### 5. 空数据与异常状态

当所选范围内 PV 和 UV 全部为 0 时，继续显示现有“暂无该事件数据”空状态，不渲染空图表。只要任一口径存在数据，图表照常渲染；切换到全零的另一个口径时，Y 轴仍以 0–1 的安全范围绘制，Tooltip 显示各日精确的 0。

请求加载、失败和重试仍由 `App` 管理，本次不改变任何错误文案或请求生命周期。

## 代码职责

- `frontend/project/analytics/trend-chart.ts`：新增无副作用的刻度生成、坐标计算、Tooltip 定位和标签碰撞选择函数。
- `frontend/project/analytics/trend-chart.test.ts`：覆盖刻度、坐标边界、标签优先级与碰撞过滤。
- `frontend/project/analytics/trend-view.tsx`：组合图表几何结果，渲染 Y 轴、网格、数据点、数值标签、命中区域和 Tooltip，并管理激活索引。
- `frontend/project/analytics/trend-view.test.tsx`：覆盖静态图表结构、具体数字、可访问说明和空状态。
- `frontend/project/analytics/styles.css`：增加网格、Y 轴、数值标签、Tooltip、命中区域与小屏滚动样式。

`track-trend.ts`、`app.tsx` 和 Backend 不需要修改。

## 数据流

```text
/api/track/trend daily
        ↓
App 保持现有请求与筛选状态
        ↓
TrendView 选择 pv 或 uv
        ↓
trend-chart 计算整数刻度、坐标与可见标签
        ↓
SVG 渲染折线、刻度、数值标签和交互层
        ↓
指针 / 键盘只更新悬浮或固定索引与 Tooltip
```

## 测试与验证

自动化测试至少覆盖：

- 最大值 3 生成 `0、1、2、3`，最大值 88 生成 `0、20、40、60、80、100`。
- 所有折线坐标处于绘图区内并与刻度轴上限一致。
- 非零标签优先保留最新点和全局最大值，且输出标签不重叠。
- 30 天视图渲染 Y 轴数字、横向网格、非零值标签和每日期命中区域。
- 图表包含完整日期与数值的可访问说明以及键盘操作提示。
- 全零趋势仍显示现有空状态且不渲染 SVG。
- PV/UV 切换仍只重绘已有数据，不发起新请求。

完成实现后运行 Analytics 相关测试、前端 lint、类型检查和 Analytics 生产构建，再运行仓库根目录的 `npm run check`。

## 验收标准

访问 `/analytics/` 并选择 `Hub / 30 天 / home_page_load / PV` 时：

- 使用上述合成数据时，Y 轴展示 `0、1、2、3`。
- `08/16` 的 `3` 和 `08/17` 的 `1` 在不重叠时常驻显示。
- 任意日期都能通过鼠标、键盘或手机点击读取完整日期和准确 PV。
- 切换 UV 或其他范围后刻度、标签和 Tooltip 使用新口径重新计算。
- 页面没有新增图表依赖，现有 API、筛选、加载、错误和空状态行为不变。
