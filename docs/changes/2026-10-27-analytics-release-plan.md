# ShotMarker 埋点网站发布

## 已确认范围

用户于 2026-10-27 明确授权将 App 和网站改动提交、合并 main 并发布。本记录负责网站 Backend、Nginx 接收格式、Analytics 与 ShotMarker 隐私页面；不发布其他前端，不修改业务数据或安全组。App 发布由 ShotMarker 仓库记录。

## 步骤

- [ ] 核对工作区与远端，保留所有用户改动；完成 Node 24 检查。
- [ ] 提交功能变更、合并 main、推送远端。
- [ ] 同步私有台账，读取当前生产配置，确认 Cardgame 无活动房间，建立针对性回滚备份。
- [ ] 部署兼容新旧记录的 Backend，只扩展现有 Nginx Track 日志字段，配置检查成功后平滑重载。
- [ ] 按现有脚本发布 Analytics 和 ShotMarker 前端。
- [ ] 只读验证公开页面/资产与构建一致、健康与新旧查询接口。接收格式使用隔离临时日志验收，不向生产 Track 写入虚构用户事件。
- [ ] 更新 current 与脱敏结果，归档本记录，公开与私有仓库分别提交、推送。

## 边界

保留单一 JSONL、历史四字段、当前权限和挂载。新增字段没有历史回填。生产配置备份及具体操作位置由私有台账维护。服务器可用与查询通过不代表真实 App Store/TestFlight 手机已经完成端到端验收。
